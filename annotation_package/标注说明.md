# 引用句标注手册(发给学生 · v2.1 正式版)

这些英文句子来自学术论文,每句都在引用某个先前的研究发现。请**独立完成、不要互相讨论、不要查原文、不要用 AI 工具**——我们要的是"人类读者的自然判断"。凭句子本身判断,没有标准答案压力;拿不准就选最接近的档,并在"备注"列写 `?` 加一句原因。

请一口气或分两次做完,疲劳了就休息;顺序做,不要跳。

## 任务 A(task_A_sentences.csv,372 句,约 2 小时)

每句都在引用至少一项先前研究。**你不需要知道、也无法知道具体是哪一项**——只判断:这句话是否在转述它所引研究的发现、转述得有多确定。一句引了多篇文献时,按本句**主要在复述的发现**判断。

每句填两格(+可选备注):

### 第 1 格:是否在转述结论(1/0)

**填 1** = 句子在复述该研究"发现了什么/什么影响什么"(哪怕说得委婉、哪怕带否定):
- "Power posing has been shown to increase risk tolerance (Carney et al., 2010)." → 1
- "Ego depletion may reduce subsequent self-control (ref)." → 1(委婉也算)
- "Recent work failed to confirm that money priming affects behavior (ref)." → 1(否定式转述也算转述)

**填 0** = 只是把该研究当**方法、范式、量表、数据集、任务材料**或泛泛背景提一下,没有复述其结论:
- "We adopted the paradigm of Carney et al. (2010)." → 0
- "Following prior work (ref), participants completed a Stroop task." → 0
- "Research on embodiment has grown rapidly (ref)." → 0(只是领域背景)

**边界判例:**
- 句子同时"用了范式"又"复述了结论" → **1**(转述优先);
- 只报样本量/方法细节("their N=42 study used...")不含结论 → 0;
- 疑问句或假设语气("Might posing affect hormones (ref)?")→ 1,但确定性给低档;
- 一句话引用多个研究、混着说 → 按**与本句主要结论**的关系判断;
- 罗列式复述("Well-known examples include reports that reading X makes people do Y [8]")→ **1**(罗列多个发现也是复述,按整句语气打分);
- 介绍某**理论/计算模型的设定**("the theory models lexical access as a cascaded process")而非经验发现 → **0**(描述理论框架≠转述发现);
- 只引用某研究的**问题、任务或刺激材料**而不提其结论 → 0。

### 残句与乱码怎么办(这批句子来自 PDF 自动抽取,一定会遇到)

- 以"…"开头、结尾被截断、断字("moti - vation")、怪空格("de ﬁ cits")→ **照常按可见部分的语义判断**,不算问题,不用备注;
- 两段文字明显拼接错乱、读不太通 → 尽力按能读懂的部分判断,备注写 `?乱码`;
- 残缺到**完全无法判断**是否在转述 → 第 1 格填 0,备注写 `?残句`(这类我们会单独复核,不会算你判错)。

### 第 2 格:确定性打分(仅当第 1 格=1;五档 0 / 0.25 / 0.5 / 0.75 / 1)

**第 1 格填 0 时,第 2 格必须留空**——不要填 0,空着就行。

衡量句子把结论**说得有多确定、多普适**。⚠️ 判的是**措辞语气**,不是结论对不对、你信不信。

| 档 | 语气 | 典型信号词 |
|---|---|---|
| **0** | 完全试探/强条件 | may, might, could, possibly, "under certain conditions", "it is speculated" |
| **0.25** | 谨慎暗示 | suggests, appears to, seems to, "preliminary evidence", "tend to" |
| **0.5** | 中性报告 | found that, reported that, observed, "has been shown to", "in their study, X did Y" |
| **0.75** | 肯定 | shows that, demonstrates, "evidence indicates", "consistently" |
| **1** | 断定/因果/公理化 | causes, proves, "it is well established that", "as is well known", 无任何限定的一般现在时断言("X increases Y") |

**边界判例:**
- **转述别人口气要降档**:"The authors claimed that X causes Y" → 作者在拉开距离,按 0.5 而非 1;
- **否定式转述照常打**:"X does not affect Y" 说得斩钉截铁 → 1;"X may not affect Y" → 0;
- 一句里既有肯定又有限定("clearly shows X, at least in students"、"was found to increase X in some contexts")→ 取二者折中(0.5 或 0.25);
- 只要出现"failed to replicate / has been questioned"这类保留信息 → 通常 ≤0.25;
- "found limited evidence that" → 0.25("found"被"limited"抵消);
- "has been shown to" 是**报告式被动**,归 0.5,不算 0.75 的断定(除非配了 consistently/clearly 这类加强词)。

## 任务 B(task_B_sentences.csv,150 句,约 40 分钟)

每句一格:**是否提及该发现"复现失败/证据不一/存在争议"(1/0)**

**填 1** 的信号:failed to replicate、replication attempts、mixed/inconsistent evidence、controversial、has been challenged/questioned、debate、"however, recent studies did not find"。
**填 0**:完全没提,当作成立的发现引用——**哪怕语气委婉也是 0**(委婉≠承认争议;只有明确提到"证据有问题"才算 1)。

**边界判例:**
- 争议必须指向**本句所引的那个发现**:泛泛提"心理学有复现危机"但没说这个发现有问题 → 0;
- 提到存在**竞争理论/不同解释**但没说证据冲突 → 0(理论分歧≠证据有问题);
- "However, X et al. failed to find this effect" → 1(引了相反证据就算,不需要出现 replication 这个词)。
