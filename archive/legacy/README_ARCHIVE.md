# Historical project files

Files in this directory preserve the previous repository layout byte-for-byte.
They document earlier collection, model calls, annotation and analyses; they are
not the specification for the current measurement reanalysis. No legacy model
or data-collection script is invoked by the root-level reproduction commands.

If inspecting a historical script, its old relative paths assume this directory
as the working directory. Historical raw material retains its original rights.
The current entry points, frozen derived inputs and interpretation are documented
in the repository-root README. Published snapshots remain under releases/ and
in the original Git tags and releases.
