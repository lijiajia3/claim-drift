verification from optional runtime-dependent byte verification. `CODE_PROVENANCE.json` records every original ZIP member and hash, every
path and verification replacement, and all copied component-file hashes. Reversing each stated
replacement recovers the original source byte-for-byte. This is a repository
organization change, not a new scientific analysis or modified outcome.

`archive/legacy/`; their original bytes and relative subtree are preserved.

1e-12 tolerance. Integer fields and text must match exactly. Retention floating-point outputs
are checked at the same tolerance; `python reproduce_retention.py --strict-bytes`
also enables the original byte gate. Actual checks found final-bit differences
in two retention CSVs on the installed runtime, so byte identity is not claimed.
The unchanged original strict reproduction script remains in the release ZIP. Runtime/path/version metadata are not claimed
to be byte-identical to the original execution record.

Actual saved-input checks completed after relocation: 44 numerical CSV tables
matched their published references, and the external-linkage entry point passed
its descriptive-count assertions. The auxiliary `event_group_plot_data.csv` is
retained as a reference file but is not regenerated by the root analysis entry
