# Separate Staunton-selected source sensitivity

The main analysis retains the conservative 105-source baseline. The additional 106-source analysis changes one scope decision: it includes RPP73 as criterion-positive for the archived selected Staunton contrast. It does not impose a unique aggregation rule across all four sites or silently change the primary cohort.

The selected count table has 25 Democratic and 95 Republican bumper-sticker observations (n=120), compared with local voter proportions .30/.70. Its unrounded Pearson goodness-of-fit statistic is χ²=4.8015873, p=.02843353, in the predicted direction. This is a reproduced Pearson p-value, not an exact-binomial p-value. The selected statistic is known; the remaining question concerns the scope of the source-level comparison.

Sources: [report, Table 2](https://osf.io/download/2jwi6/), [count workbook](https://osf.io/download/ftzbj/), [archived selection script](https://osf.io/download/hau4p/), [registered protocol](https://osf.io/download/n6m5d/), and [registration](https://osf.io/hctz9/).

The extension gives 106 sources (57 criterion-negative, 49 criterion-positive), 15,302 text units and 8,443 Qwen-positive texts. Its frozen-model mean-score contrast is −0.00326 [−0.02074, +0.01458], with 97 eligible sources. Transformed drift and model-score event contrasts are unchanged because the added source does not meet their eligibility rules.

The added 22 texts contain no match to either primary literal family. Thus the 87 adverb-text and 304 replication-word-text totals are unchanged. Five added texts contain a lowercase modal form. The all-text lexical event sample grows to 86 sources, with replication-word incidence contrast −0.65 percentage points [−2.66, +1.20]. The positive-text event sample and same-72-source filter comparison remain unchanged.

All frozen token rules remain unchanged. This sensitivity addresses an explicit inclusion convention; it is not selected to obtain a desired point estimate or statistical significance. The choice of a final primary source-level rule requires a clear, consistently stated scientific scope.
