# Frozen reproduction inputs and reference tables

These files are byte-identical extracts from the published v3 Online Resources.
`core/`, `literal/`, `selection/`, `retention/` and `external/` correspond to the
root-level entry points. Outputs/reference_outputs/reported_results in these
folders are the **published reference tables**, not newly generated results.
Root-level commands write only to `results/`.

Original component READMEs and manifests describe their original ZIP layout.
For the relocated layout, use the root README and docs/CODE_PROVENANCE.json;
original immutable ZIPs and metadata remain under releases/.

The input representations contain frozen derived counts, scores and selected
external-linkage audit fields. They do not redistribute the original article
full texts or private annotation-export metadata. Component attribution and
rights notices remain applicable; MIT applies to the authors' code, not to
third-party data, text or publisher templates.
